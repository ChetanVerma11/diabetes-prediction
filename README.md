# Diabetes Prediction System

An AI-powered web application that predicts diabetes risk based on patient health metrics using Machine Learning.

## Features

- 🧠 **ML Model**: Random Forest Classifier with 78% accuracy
- 📊 **Real-time Predictions**: Instant diabetes risk assessment
- 📱 **Responsive Design**: Works on all devices
- 🎨 **Modern UI**: Beautiful gradient design with icons
- 📈 **Personalized Recommendations**: Health tips based on results

## Tech Stack

### Backend
- Flask (Python web framework)
- Scikit-learn (Machine Learning)
- Pandas & NumPy (Data processing)

### Frontend
- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (ES6+)
- Font Awesome Icons
